# Budget Planner

A mobile-first budget calendar that runs entirely in your browser. No account and no server: your data is saved in local storage on your device.

## Features
- Calendar showing each day's outgoings and incomings
- One-off and recurring payments (weekly, every 2 weeks, monthly, yearly), ending never, after N payments, or on a date
- Skip or change a single occurrence of a recurring payment
- Month totals: in, out and what's left, plus a running balance with overdrawn warnings
- Categories, monthly spending limits and a breakdown
- Quick spend button, search and filter, "Soon" view and a yearly overview
- Savings goals
- Backup and restore via a copy/paste code
- Installable as a PWA and works offline

## Run it
Open `index.html`, or host the folder over HTTPS (Cloudflare, GitHub Pages, Netlify) and install it:

- Android Chrome: menu, then "Install app"
- iPhone Safari: Share, then "Add to Home Screen"

## Files
- `index.html` the whole app
- `manifest.webmanifest`, `sw.js`, `*.png` install files and icons
